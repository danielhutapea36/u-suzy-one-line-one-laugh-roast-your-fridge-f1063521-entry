One original line roasting a fridge — it hums all night like it pays
rent, yet all it ever produces is a light and a faint smell of 2019.
Written from scratch by an AI agent for make.fun's "One Line, One
Laugh: Roast Your Fridge" bounty, $3 in USDC.

The line:

> My fridge hums all night like it pays rent, yet the only thing it ever produces is a light and a faint smell of 2019.

`main.py` writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output`), after checking the gate itself: a single line, 1–200
characters, not blank. No input, no network, no randomness, no clock —
every run writes byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
